# Contribuição ao Guia Hermes Agent do LABHDUFBA

- Fontes técnicas devem ser a documentação oficial do Hermes Agent ou o repositório oficial da Nous Research.
- Declare a versão do Hermes quando uma instrução depende dela.
- Não inclua chaves, tokens, senhas, identificadores privados ou exemplos que induzam a exposição de segredos.
- Distingua: terminal, chat, prompt em linguagem natural e ação com efeito externo.
- Não descreva MemPalace como funcionalidade nativa do Hermes; documente-o como extensão específica quando aplicável.
- Antes de publicar alterações, execute `python3 scripts/validate.py` e `bash scripts/build_pdf.sh`.
